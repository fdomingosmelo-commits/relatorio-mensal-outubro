# Núcleo de Scrum Masters — TIS

Apresentação executiva em HTML/CSS/JavaScript, optimizada para GitHub Pages. Sem dependências externas.

## Publicar no GitHub Pages
1. Crie um repositório ou abra o repositório de destino.
2. Envie `index.html` para a raiz do repositório.
3. Em **Settings → Pages**, seleccione **Deploy from a branch**, `main`, `/ (root)` e **Save**.
4. Aguarde a publicação do endereço `https://<utilizador>.github.io/<repositorio>/`.

Navegação: setas do teclado ou botões inferiores. O botão PDF abre a impressão do navegador.
